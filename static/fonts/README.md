# Fontes self-hosted

Arquivos `.woff2` obtidos do Google Fonts e servidos localmente para que o
LeoBooks funcione sem CDN:

- **Fraunces** — display serifada, SIL Open Font License 1.1.
- **Newsreader** — leitura e citações, SIL Open Font License 1.1.
- **Inter** — interface, SIL Open Font License 1.1.

Os arquivos foram baixados dos subsets `latin` e `latin-ext` e não foram
modificados. As licenças originais estão disponíveis em
<https://openfontlicense.org/> e nos repositórios de cada família no Google
Fonts.
